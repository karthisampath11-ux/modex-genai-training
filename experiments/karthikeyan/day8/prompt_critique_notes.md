# Prompt Critique Notes
## Objective
 Understand how high-quality prompts are structured and identify techniques that can be reused in future projects.

## Prompt Analysis 1
### What I Observed
The prompt was well organized and easy to follow.
It clearly explained:
 1.What role the model should take.
 2.What task needs to be completed.
 3.What format the response should follow.
 4.What rules or limitations should be followed.
### Why It Works
Each section has a purpose.
 1.The role helps the model understand how it should respond.
 2.The task section clearly explains the objective.
 3.The output format reduces confusion and makes the response more consistent.
 4.The instructions and constraints help avoid unnecessary mistakes.
### What I Would Use In My Own Prompts
 1.Clear role definition.
 2.Specific task instructions.
 3.Defined output format.
 4.Important constraints and rules.
### My Learning
A good prompt is not just a question. It gives the model clear guidance about the task, expected output, and boundaries. This helps improve the quality and consistency of the response.
